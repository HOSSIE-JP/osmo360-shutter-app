# 実機受入チェックリスト

実施者：ユーザー。初期状態は全項目未実施。JSONログと元画像を手元に保存し、個人の位置情報を公開リポジトリへコミットしないでください。

最初に、端末名／Android・Chromeの版／カメラのファームウェア／画像形式・解像度・セルフタイマー設定／アプリのコミットを記録します。

| ID | 操作 | 期待結果・確認内容 |
|---|---|---|
| H01 | Bluetooth・GPS許可を拒否 | エラー表示。無断の撮影要求なし。再許可で復旧 |
| H02 | カメラを接続、承認／拒否 | コードが一致。拒否時は未承認状態で撮影不可 |
| H03 | 動画モードのまま手動撮影を試す | シャッター無効。写真モードの状態通知後に有効 |
| H04 | 写真設定別に10回ずつ手動撮影 | 要求数、カメラACK、busy→idle、実ファイル数を照合 |
| H05 | GPS未取得／取得直後／安定後に撮影 | GPS必須では欠測時保留。元画像のEXIFとアプリ座標を照合 |
| H06 | 高度なし・衛星数0・品質不明 | GPS送信の保留／実カメラの受理状況を記録 |
| H07 | GPSを失って10秒待つ | 古い位置でGPS必須撮影しない。カメラが旧座標を保持するか元画像で確認 |
| H08 | UTC16時・JST1時付近など日付境界 | UTC+8変換と元画像日時の対応を検査。必要ならUTC設定で比較 |
| H09 | 歩行→停止を20回、同位置で60秒静止 | 各移動後に1回。立ち止まり続けても連写しない |
| H10 | 低速歩行、ポール揺れ、画面操作 | ジャイロ／加速度／歩数閾値を調整。誤撮影を記録 |
| H11 | 自動の直前に手動を連打 | 共有クールダウンで要求が重複しない |
| H12 | 要求直後にカメラの電源OFF | 結果不明または動作検知として保存。自動再送なし |
| H13 | HOME・他アプリ・消灯→復帰 | 自動撮影が一時停止。明示再開後、再移動で撮影 |
| H14 | 30分以上、前面のまま歩行 | センサー/GPS/音声継続。電池・温度・保存容量を確認 |
| H15 | プロジェクトを2つ作成・編集・切替 | セッションと履歴が混ざらない |
| H16 | セッション終了・リロード・アプリ終了 | 保存履歴が復元。未確定要求は再送されない |
| H17 | セッション・プロジェクト削除 | 指定した記録だけ削除。確認ダイアログあり |
| H18 | 坂や階段を歩き3Dビューを回転・拡大 | 高低差の傾向、番号付き撮影位置。GPS垂直誤差も確認 |
| H19 | APIキーなし／有効／無効／削除 | 未設定時は外部地図なし。設定時のみ地図。失敗時も3D使用可 |
| H20 | JSON・CSV・GPXを書き出す | 時刻・件数・座標一致。APIキーを含まない |
| H21 | PWAインストール後、再起動・オフライン起動 | UIと履歴閲覧可能。地図はネット接続が必要 |
| H22 | 新版公開中に撮影し、終了後全タブを閉じる | 撮影中の強制リロードなし。再起動で新版に更新 |
| H23 | DJI Mimo等で画像を書き出す | 元画像と書き出し後のGPS保持を別々に確認 |

不具合報告に有用な内容：発生手順、端末・FW・写真設定、発生直前のログ、実画像数、元画像のGPS有無、ブラウザー権限状態。公開するログから実座標は削除してください。
